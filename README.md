# Bank Customer Churn Analysis Dashboard

## Project Overview
This project analyzes customer churn patterns in a simulated banking dataset using Python and Power BI. The goal is to identify customer segments with higher churn risk and recommend data-driven retention strategies.

## Business Problem
Customer churn is a major challenge for banks because losing customers impacts revenue, loyalty, and long-term growth. This dashboard helps identify which customer groups are more likely to leave and what actions banks can take to improve retention.

## Tools Used
- Python
- Pandas
- Power BI
- DAX
- Excel/CSV
- ## Dataset Note
This project uses a simulated banking dataset for learning and analysis purposes. The countries shown in the dataset, such as France, Germany, and Spain, are illustrative and do not represent a specific real bank.

## Key KPIs
- Total Customers: 10K
- Churned Customers: 2K
- Churn Rate: 20.37%
- Average Balance: 76.49K

## Key Insights
- Inactive customers have a higher churn rate compared to active customers.
- Customers aged 30–50 contribute the highest share of churn.
- Female customers show slightly higher churn compared to male customers.
- Churn varies across regions, suggesting the need for targeted retention strategies.
- ## Recommended Retention Strategies
- Re-engage inactive customers through personalized communication and offers.
- Focus retention campaigns on the 30–50 age group.
- Encourage cross-selling and product bundling to increase customer stickiness.
- Improve customer experience through better digital banking support.
- Use region-specific retention strategies based on customer behavior.
